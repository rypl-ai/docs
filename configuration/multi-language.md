# Languages

Rypl answers each comment in the language it was written in. One agent with one knowledge base covers every market: a comment in French gets its answer in French, one in Polish an answer in Polish, and there's nothing to set up per language.

Under ads that's common: [RYPL data for Q3 2026](https://www.rypl.is/blog/ad-comment-statistics-2026) found that 70% of analyzed comments were in a language other than English, and that about 4 in 5 advertisers received comments in at least two languages.

---

## Reply language

Each channel has its own **Reply language**, under **Replies** once you click the channel's row on **Channels**. Changes apply straight away.

- **Detect automatically** (default): each reply matches the comment's language.
- **A specific language**: all replies on that channel use it, whatever language the comment is in. Handy for a Page aimed at one country.

---

## Knowledge base in one language is enough

The agent uses your knowledge base whatever language the comment is in, so you don't need to translate it. Do add what really differs by market:

- product names that change between countries;
- prices in local currencies;
- shipping and return terms that differ by country.

---

## Tone across languages

- **Formal or informal "you".** In languages that have both (French *tu/vous*, German *du/Sie*, Polish *ty/Pan*), say which to use in the agent's instructions.
- **Humour and idioms** don't always travel. A playful brand voice may need a plainer version for some markets.
- **Check replies in each language** you target during the first week, ideally with a native speaker.

---

## Reading other languages in the inbox

- **Translate**, in the conversation header, shows a comment in another language.
- The **Language** filter shows comments in one language at a time.

---

## Moderation in any language

- Rypl reads comments for meaning in any language, so intent labels, **Filter by tone** and moderation rules work whatever language a comment is written in.
- **Banned words** match the text you type, so add the words in every language you need, for example a competitor's name in its local spelling.
- **Moderation rules** (Pro and Ultra) are written once, in any language, and checked against comments in every language. In languages with less online text, check what a new rule catches in **Review first** before switching to **Apply automatically**.

# Configuration

Rypl keeps its settings in three places:

- The **agent**, under **AI Agents**, holds how replies sound and what they know: instructions, tone, knowledge base, where and how soon it replies, and reply rules.
- The **channel** (a Facebook Page with its Instagram account, or a TikTok ad account) holds whether replies are on and which agent answers, both right on its row in **Channels**. Click the row for its reply language, emojis and moderation.
- **Global rules**, the card at the top of **Channels**, hold moderation rules and banned words for every channel at once.

Your plan and the **MCP and API Keys** block for connected apps are in **Settings**.

## What's on which plan

| Setting | Simple | Pro | Ultra |
|---|---|---|---|
| Agent instructions, tone, knowledge base | ✅ | ✅ | ✅ |
| Replies to, How soon, reply language, emojis | ✅ | ✅ | ✅ |
| Intent detection | ✅ | ✅ | ✅ |
| Banned words (global and per channel) | ✅ | ✅ | ✅ |
| Filter by tone, Spam & media filter | ✅ | ✅ | ✅ |
| Block author | ✅ | ✅ | ✅ |
| Like positive comments (Facebook) | ✅ | ✅ | ✅ |
| Suggest improvements | ✅ | ✅ | ✅ |
| Read the post | — | ✅ | ✅ |
| Moderation rules in plain words, Review first | — | ✅ | ✅ |
| Reply rules and thank-you replies | — | ✅ | ✅ |
| API and MCP server | — | ✅ | ✅ |
| Remember the conversation | — | — | ✅ |
| AI agents | 1 | Unlimited | Unlimited |
| Accounts / channels with AI replies | 1 / 3 | 5 / 20 | Unlimited |

On Simple, moderation rules stay saved but don't run; they start working when you move to Pro or Ultra.
